Duskfire is a complete arcade runner: Pip the firefly runs 1500 metres through a night meadow to reach dawn. Jump thorn bushes (double jump), slide under night moths, catch glowing spores to build a combo, grab a sunpetal for a one-hit shield. Three hearts, ten levels that get faster, a win screen at dawn and a game-over screen with restart. All art is drawn in canvas, all sound is synthesised with WebAudio, and the game runs from static files with no network request.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Space / Up / click jumps, Down / S dives and slides, P pauses, M mutes, R restarts.
